# Missão – Módulo 1: Python 🐍

Este repositório contém os exercícios do **Módulo 1 da Missão da 42**, cujo objetivo é
introduzir a manipulação de variáveis e a lógica básica de programação utilizando Python.

## Objetivo do Módulo
- Aprender a declarar e manipular variáveis
- Trabalhar com concatenação de strings
- Realizar operações simples com números
- Interagir com o usuário via entrada padrão (`input`)

## Estrutura do Repositório

- **ex00/**  
  Exibição de nome utilizando variáveis (`first_name` e `last_name`)

- **ex01/**  
  Concatenação de nome e sobrenome em uma única variável (`whole_name`)

- **ex02/**  
  Cálculo da idade somando o valor 42

- **ex03/**  
  Interação com o usuário solicitando nome e sobrenome
